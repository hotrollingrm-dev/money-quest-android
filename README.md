# MONEY QUEST (Android)

แอปจัดการชีวิตและการเงินส่วนตัว — กะงาน UACJ 3G2S, OT, ภาษี, หนี้, รายจ่าย, เป้าหมาย และอ่านสลิปธนาคารในเครื่อง

## โครงสร้าง
- `web-src/` — ตัวแอป (หน้าจอ + ระบบคำนวณ) แก้ที่นี่
  - `engine.js` ระบบคำนวณ · `slip.js` ตัวอ่านสลิป · `app1–4.js` หน้าจอ · `test.js` ชุดทดสอบการคำนวณ
- `android/` — ส่วน Android (Capacitor) · `MQNativePlugin.java` อ่านอัลบั้มสลิป วิดเจ็ต อัปเดต
- `tools/build-web.js` — ประกอบ `web-src` เป็น `www/`
- `native-version.txt` — เพิ่มเลขนี้เมื่อแก้โค้ด Android (แอปจะขอติดตั้ง APK ใหม่) · ถ้าไม่เพิ่ม แอปจะอัปเดตเฉพาะหน้าจอเอง

## การอัปเดต
ทุก push เข้า `main` → GitHub Actions ทดสอบการคำนวณ → สร้าง APK ที่เซ็นแล้ว + `web.zip` + `manifest.json` → Release ใหม่
แอปเช็ค Release ล่าสุดตอนเปิด: เปลี่ยนแค่หน้าจอ = โหลดเองไม่ต้องติดตั้ง · เปลี่ยนส่วน Android = กดติดตั้งทับครั้งเดียว

## Secrets ที่ต้องมี
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD` — กุญแจเซ็นแอป ต้องใช้อันเดิมตลอด ห้ามหาย

## ความเป็นส่วนตัว
สลิปถูกอ่านในเครื่องเท่านั้น ไม่มีการส่งรูปออก · ห้ามใส่สลิปจริงหรือข้อมูลการเงินลงใน repo นี้ (repo เป็น public)
